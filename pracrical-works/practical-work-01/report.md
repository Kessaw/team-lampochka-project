7. Вывод
Использование системы контроля версий Git и платформы GitHub позволило команде «Лампочка»:

Организовать единое структурированное рабочее пространство без риска перезаписи файлов друг друга.

Закрепить персональную ответственность: благодаря веткам (feature/) и истории коммитов прозрачно виден вклад каждого участника команды.
