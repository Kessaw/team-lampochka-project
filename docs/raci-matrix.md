# Матрица ответственности RACI

Обозначения:
* R (Responsible / Исполнитель) — выполняет работу по задаче.
* A (Accountable / Ответственный) — несет конечную ответственность за результат и утверждает работу.
* C (Consulted / Консультант) — предоставляет необходимую информацию и консультирует при выполнении.
* I (Informed / Информируемый) — информируется о ходе или результатах выполнения задачи.

## 1. Матрица ответственности по задачам проекта

| Задача / Этап проекта | Руководитель (Макаров М.) | Архитектор (Кирюхина К.) | Специалист по данным (Кудряшов В.) | Специалист по тестированию (Козлов К.) | Программист (Лайкевич А.) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| Формирование требований и плана работ | A / R | C | C | C | I |
| Проектирование архитектуры | A | R | C | C | C |
| Подготовка и структурирование данных | A | C | R | C | I |
| Разработка программного функционала | A | C | C | C | R |
| Тестирование функционала | A | C | C | R | C |
| Исправление выявленных дефектов | A | C | C | C | R |
| Подготовка проекта к демонстрации | A | C | C | R | R |

## 2. Закрепление обязанностей по работе с Git-репозиторием

На основе матрицы RACI обязанности по администрированию и поддержке репозитория распределяются следующим образом:

| Обязанность в Git / GitHub | Responsible (Исполнитель) | Accountable (Ответственный) |
| :--- | :--- | :--- |
| Создание и настройка репозитория | Руководитель (Макаров М.) / Архитектор (Кирюхина К.) | Руководитель (Макаров М.) |
| Поддержание структуры папок и файлов | Все участники (для своих разделов) | Руководитель (Макаров М.) |
| Написание отчетов по практическим работам | Все участники (согласно ролям) | Руководитель (Макаров М.) |
| Внесение коммитов с понятными сообщениями | Каждый участник (за свои изменения) | Руководитель (Макаров М.) |
| Проверка пул-реквестов (Pull Requests / Review) | Руководитель (Макаров М.) / Архитектор (Кирюхина К.) | Руководитель (Макаров М.) |
| Слияние веток (Merge) | Руководитель (Макаров М.) | Руководитель (Макаров М.) |
| Резервное копирование и поддержание актуальности | Все участники | Руководитель (Макаров М.) |
