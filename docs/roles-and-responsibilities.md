# Распределение ролей в команде «Лампочка»

В рамках разработки проекта «Сервис подбора маршрутов прогулок» в команде «Лампочка» определено распределение профессиональных ролей с учетом индивидуальных зон ответственности участников.

## Состав команды и распределение ролей

### 1. Макаров Михаил — Руководитель разработки
* Профессиональный стандарт: 06.017 «Руководитель разработки программного обеспечения»
* Основная зона ответственности: Координация разработки, распределение задач, контроль сроков и итогового результата.
* Обоснование выбора: Требуется единый центр управления для координации работы всех 5 участников, распределения задач, разрешения разногласий и контроля своевременной подготовки результатов к демонстрации.

### 2. Кирюхина Ксения — Архитектор ПО
* Профессиональный стандарт: 06.003 «Архитектор программного обеспечения»
* Основная зона ответственности: Архитектура системы, выбор технологического стека, проектирование структуры компонентов, базы данных и API.
* Обоснование выбора: Проекту необходима заранее продуманная техническая модель и согласованная структура системы, определяющая границы компонентов и правила их взаимодействия до начала написания кода.

### 3. Кудряшов Виталий — Специалист по данным
* Профессиональный стандарт: 06.042 «Специалист по большим данным»
* Основная зона ответственности: Сбор, подготовка, обработка и структурирование данных о маршрутах прогулок (длина, сложность, тип местности, объекты).
* Обоснование выбора: Качество подбора маршрутов напрямую зависит от полноты и корректности исходных данных, что представляет собой отдельное трудоемкое направление работ.

### 4. Козлов Кирилл — Специалист по тестированию
* Профессиональный стандарт: 06.004 «Специалист по тестированию в ИТ»
* Основная зона ответственности: Разработка тестовых сценариев, поиск и фиксация дефектов, проверка соответствия функционала требованиям.
* Обоснование выбора: Для стабильной работы прототипа необходим независимый контроль качества, валидация фильтров и проверка логики подбора маршрутов.

### 5. Лайкевич Андрей — Программист
* Профессиональный стандарт: 06.001 «Программист»
* Основная зона ответственности: Написание программного кода, разработка пользовательских сценариев, создание API и интеграция компонентов сервиса.
* Обоснование выбора: Реализация проектных решений архитектора и интеграция подготовленных данных в действующий, чистый и легко сопровождаемый программный код.
