# Team «Лампочка» Project

## О проекте

Данный репозиторий является единым рабочим пространством команды **«Лампочка»** для выполнения практических и самостоятельных работ в рамках учебного проекта.

Репозиторий предназначен для:

* хранения документации проекта;
* распределения ответственности между участниками команды;
* хранения результатов практических работ;
* совместной работы с использованием Git и GitHub;
* фиксации вклада каждого участника в истории изменений.

Все материалы проекта организованы в соответствии с установленной структурой репозитория.
